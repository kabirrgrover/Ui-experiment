# Chat

The guided conversation that gathers what the AI needs before it drafts a document.

- `.db-msg--ai`: no bubble. "docbuilder" in Shantell Sans, then `body` text straight on white. `.db-msg__aside` adds a short `aside` note in `blue`.
- `.db-question`: one question at a time under a thin ink rule. Small uppercase step counter, the question in big thin Coming Soon (lowercase, HeyTea style), then chips.
- `.db-msg--user`: right-aligned soft bubble on `paper-sunk`.
- `.db-composer`: the input well with the primary Send button.

**Voice**: a helpful site engineer. Short sentences, no exclamation marks, no emoji. Says what happens next and how many questions are left. Never invents numbers; asks.
