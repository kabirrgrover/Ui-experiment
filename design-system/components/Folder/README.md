# Folder

A pastel folder with its latest documents peeking out the top, after the "Half-Year Tucked Inside My Folder" reference. One folder per document type (or per project) on the folders page.

**Consumer provides** `data-color` (`pink`, `sage`, `peach`, `butter`, `lilac`, `sky`), up to three items inside `.db-folder__items` (thumbnails of the latest documents, a sticker, a sticky note; each absolutely placed with its own `left`, size and small rotation), the label (`label`, Shantell Sans bold) and a count pill.

On hover the items lift out a little with `ease-slap`. The whole folder is one button that opens the list.
