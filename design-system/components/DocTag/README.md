# DocTag

A small label for the document type: SR in `safety`, MR in `blue`, PEP in `green`. Set `data-type="sr" | "mr" | "pep"`.

Use on chat headers, folder cards and document title blocks. For the big, playful version use the "Hello, I'm" stickers (`hello-sr`, `hello-mr`, `hello-pep`). A new document type gets a new `data-type` rule with a palette colour; never invent a hue.
